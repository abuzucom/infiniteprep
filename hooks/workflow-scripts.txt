# Repository scripts the command execution gate recognizes.
#
# Line format: <verdict> <script> [argument ...]
#
# Verdicts:
#   allow          runs without a prompt and only inspects the repository
#   consent-read   routes to consent and only inspects the repository
#   consent-write  routes to consent and writes files
#
# Arguments match literally except these placeholders:
#   <revision>  one Git revision name
#   <path>      one repository-relative path
#   <paths>     zero or more repository-relative paths, in the last position only
#
# The shapes mirror the Makefile, .pre-commit-config.yaml, and CI workflows,
# plus the local-only report and advice flags.
