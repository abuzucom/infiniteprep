Music library preparation for DJs

Prepare every track with care.

InfinitePrep is a desktop app for reviewing music metadata, analyzing tracks, and making safe, reversible library changes.

Today

Build a clear workflow from file inventory to reviewed tags, verified writes, and recovery.

01 / What it does

A careful workspace for a working music library.

Import tracks, inspect metadata and analysis, choose the changes to keep, then write tags with backups and a restore path.

01

Understand the collection

Inventory files, flag duplicates, and review track details in one desktop workspace.

02

Review before changing

Compare existing tags with proposals from local audio analysis and metadata sources.

03

Write with a way back

Preview edits, preserve unmanaged tags, verify each write, and restore from a backup.

02 / Direction

One trusted place to prepare music for performance.

The project is growing from a safe tag editor into a broader preparation workflow. Every suggestion should remain inspectable and under the DJ's control.
